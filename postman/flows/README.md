# Historical cloud flows

Previously published Smoke and Personal Finance visual flows predate the spaces-only API. They are historical artifacts and have not been updated or published by this change. Do not run the old financial flow against the current API.

Use the maintained local `postman/collections/smoke` and `postman/collections/space-finance` collections. The latter creates a space explicitly and keeps request assertions alongside the source. See [the local guide](../README.md).
