# Удаление и архивирование сущностей

Все маршруты требуют JWT. Успешный `DELETE` возвращает `204` без тела. Отсутствующая либо уже физически/логически удалённая цель возвращает `404`; запрет из-за исторической зависимости — `409`.

| Сущность                      | DELETE                                                                                             | Связанные данные                                                                                                | Архивирование                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Счёт пространства     | Только при нулевом начальном остатке и полном отсутствии операций по `accountId`/`sourceAccountId` | Для пустого счёта каскадно удаляются только snapshots                                                           | `POST /spaces/:spaceId/accounts/:id/archive`; новые операции запрещены, история читается |
| Личная или пространствовая операция | Soft delete с `deletedAt/deletedBy`; повтор — `404`                                                | Балансы затронутых счетов компенсируются ровно один раз; история продолжает блокировать удаление справочников   | Не применяется                                                                             |
| Категория расходов            | Физически удаляется только без операций, лимитов и планов                                          | Проверка и удаление сериализованы с конкурентными назначениями                                                  | `PATCH .../expense-categories/:id` с `isArchived: true`; новые назначения запрещены        |
| Лимит расходов                | Физическое удаление leaf-записи                                                                    | Категория и операции не меняются                                                                                | Не применяется                                                                             |
| План                          | Только активный план без созданного расхода                                                        | Закрытый план и origin-расход сохраняются                                                                       | `POST /spaces/:spaceId/plans/:id/archive`; архивные планы исключены из списка                              |
| Долг                          | Только долг без погашений и origin-дохода                                                          | Погашения и доход сохраняются                                                                                   | `POST /spaces/:spaceId/debts/:id/archive`; архивные долги исключены из списка                              |
| Пространство                        | Root soft delete                                                                                   | Active memberships завершаются с `space_deleted`, pending invitations отзываются; финансы и события сохраняются | Публичного восстановления и доступа к архиву нет                                           |
| Пользователь                  | Необратимая staged-очистка после step-up                                                           | Личный бюджет и auth-секреты удаляются; пространствовая история остаётся со ссылкой на PII-free tombstone             | Не применяется                                                                             |

## Удаление пользователя

`POST /auth/account-deletion` принимает:

```json
{
  "password": "current password",
  "secondFactorCode": "012345"
}
```

`secondFactorCode` обязателен, если у пользователя включён TOTP. Владелец неудалённой пространства получает `409` до передачи владения либо удаления пространства. Принятый запрос возвращает `202`, сразу переводит пользователя в `deletion_pending`, увеличивает `authVersion` и блокирует старые JWT и новый login.

Фоновая очистка необратима. Она оставляет только стабильный `_id`, `status: deleted`, `deletedAt` и технические timestamps пользователя. Имя, email, password hash, 2FA, challenges, IP и User-Agent удаляются; пространственные операции, memberships, invitations и membership events не переписываются и не удаляются.

Worker запускается командой `npm run user-deletion:work`. Команда обрабатывает доступные этапы до опустошения очереди; lease не позволяет двум workers выполнять один этап одновременно.

## Пространственные планы

Plan и category locks ограничены spaceId. Любой active/closed/archived Plan блокирует удаление его категории с 409. Архив категории сохраняет историю, но запрещает новое назначение и исполнение плана. Активный неархивный план без расхода удаляется с 204 (повтор 404); закрытый, архивный или связанный с расходом — 409. `POST /spaces/:spaceId/plans/:id/archive` возвращает 204 (повтор 404); архивный detail читается, PATCH/close — 404.

Закрытие создаёт expense origin в одной транзакции. Обычное исправление/soft-delete расхода не открывает план и не удаляет expenseId/origin. Архив плана не меняет расход, архив счёта замораживает его изменение/удаление. При удалении пространства Plan сохраняется без доступа; worker удаления автора сохраняет все планы с обезличенным actor.

## Пространственные долги и погашения

Debt без истории, origin-доходов и архива удаляется с204, повтор404. Любая история, включая полностью отменённую, защищает Debt DELETE с409. Архив долга возвращает204 (повтор404), сохраняет доходы/историю и запрещает PATCH/repay/cancel с404; read включает архивную историю.

Отмена repayment — POST cancel, 200 {debt,repayment}, повтор409. Financial отмена атомарно восстанавливает remaining/status и soft-delete income с компенсацией исходной даты; noncash не двигает деньги. История, incomeId/origin сохраняются. Обычный space income PATCH/DELETE возвращает409 после обычных прав/активного account; архивный account даёт404, в том числе при financial cancel. Некассовое погашение/отмена счёта не требуют. История пространства остаётся после удаления пользователя или пространства. Подробные DTO/статусы — space-finances-api.md.
