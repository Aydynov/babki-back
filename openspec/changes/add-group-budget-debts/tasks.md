# Tasks

Цель: общие Debt/DebtTransaction для личного и группового бюджета; only receivable, financial/noncash repay и атомарная отмена. Контракт: specs/group-budget-debts/spec.md и design.md. NestJS/Mongoose, один supplied ClientSession, прежние personal DTO/денежные политики. Этап выполняется существующим OpenSpec apply; до отдельной команды реализации код не менять.

## Review focus

- Конкурентные 60+60 при remaining100 не должны оставлять два дохода либо потерянное уменьшение (1.1/3.4).
- Отзыв manageTransactions у автора погашения не должен оставлять право отменить чужой долг (2.1/3.4).
- Отмена потраченного/backdated income должна компенсировать исходную дату один раз, включая negative cash (3.2/3.4).
- Частично заполненный owner/string ID/конкурентное назначение и конфликт parent не должны менять владельца или legacy balances (4.1).
- Архивный счёт/долг, ошибочный incomeId и actor failure не должны оставлять half-cancelled историю (3.2–3.4/4.3).
